# ROS-GP-GRG Experiment Feasibility Verification

Saved preliminary study showing that ROS/Gazebo navigation, GP updates, GRG replanning and common-input reconstruction evaluation can run with MI, EMSE and fixed-weight WIVR.

Status: Executed in a simplified node-sensing scene. Numerical outputs are pilot evidence, not a final policy ranking; continuous sensing, SRF and Adaptive WIVR remain unverified.

Results and figures: [Comparison.ipynb](Comparison.ipynb).
