# Description

Recordings made with WELL-E with RTK (receiving RTCM corrections from base station ~30 km away). Temperature recorded seperately with HOBO sensor. 

The path followed is identical within ~2m across each run (track marks formed were followed along with flags that were spaced ~5m apart). Path is in lawnmower formation similar to the initial test run found here: https://mcmasteru365.sharepoint.com/sites/ARCO-Lab-Datasets/Shared%20Documents/Forms/AllItems.aspx?viewid=9dcf4235%2D3a3a%2D46c1%2D92a1%2D2e1603b5bdfd&id=%2Fsites%2FARCO%2DLab%2DDatasets%2FShared%20Documents%2FWELL%2DE%2Fjohnson%2Dbaseball%2Ddatasets%2F2026%2D11%2D03%2Djohnson%2Dbaseball%2FDescription%2Emd&parent=%2Fsites%2FARCO%2DLab%2DDatasets%2FShared%20Documents%2FWELL%2DE%2Fjohnson%2Dbaseball%2Ddatasets%2F2026%2D11%2D03%2Djohnson%2Dbaseball. 

Main difference is the gap in the bottom left corner is filled out after it was decided to drive across the infield.

November 17 recording has video as well (not yet uploaded) but filtered bag has all zed topics removed to reduce bag size.
All other bags don't have zed.
